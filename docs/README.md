# Better Mob Buckets

Like catching a fish in a water bucket, but for cows, villagers, horses,
zombies and almost everything else. Players craft a bucket for one kind of mob,
scoop the mob up, carry it around, and let it out somewhere else.

It is a survival tool, not a cheat: a catch only works half the time, a miss
breaks the bucket, pets belong to their owners and claims are respected.

## Which applies to you?

* **I am installing it.** [Install Better Mob Buckets](getting-started/install.md).
  Two minutes, and every recipe is in the players' recipe books straight away.
* **I play on a server that has it.** [Catching mobs](using-it/catching.md)
  explains everything.
* **I want to change the odds or the recipes.** [Settings](reference/settings.md)
  and [The mob list](reference/mob-list.md).

## Will it work on my server?

| | |
| --- | --- |
| Server software | **Paper** or **Purpur** |
| Minecraft version | **1.21.1 or newer**, or **26.x** |
| Java | **21** for 1.21, **25** for 26.x |

{% hint style="warning" %}
**It will not work on Spigot, CraftBukkit or Folia.** It is built on Paper.
{% endhint %}

It is free, and works with GriefPrevention claims, PlaceholderAPI and
Advanced Player Metrics stats when those are installed. None of them is
needed.

## What players get

* **A bucket per mob.** An empty bucket, 3 slime balls and 3 of an item that
  matches the mob, in any order. Every recipe is in the recipe book.
* **Half a chance, or three in four.** A fresh bucket catches half the time.
  Strengthened in a brewing stand, three tries in four.
* **The mob stays itself.** Its name, age, health, colours, owner, a horse's
  speed and a villager's trades all come along.
* **Fair play.** Only owners catch their pets, claims are respected, and mobs
  made by other plugins stay put.
